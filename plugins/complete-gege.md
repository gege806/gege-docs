### 格格制作 CDK 系统使用文档
一、系统简介
格格制作 CDK 系统是一款基于 ESX 框架开发的 CDK 管理与兑换解决方案，支持物品、金钱和车辆三种类型的奖励发放，具备完整的权限管理和 CDK 生命周期控制功能
二、安装说明
将系统文件放入resources目录
在server.cfg中添加ensure complete-gege-esx-cdk-system
启动服务器，系统会自动创建所需数据库表
数据库表名默认为gege_cdk，可在server/main.lua中修改
三、权限管理
默认支持以下用户组使用管理员功能：
superadmin：超级管理员
admin：管理员
可在server/main.lua中修改Config.AllowedGroups配置项自定义权限组
四、玩家使用指南

1. 打开 CDK 兑换界面
   游戏内输入命令：/cdk
   或通过其他触发方式（如 NPC 交互、菜单按钮）打开

2. 兑换 CDK
   在输入框中填写获取到的 CDK 码
   点击 "立即兑换" 按钮
   系统会自动验证 CDK 有效性并发放对应奖励
   兑换结果会通过游戏内提示告知

3. 常见问题
   提示 "CDK 不存在"：请检查 CDK 码是否输入正确
   提示 "该 CDK 已被使用"：此 CDK 已被其他玩家兑换
   提示 "该 CDK 已过期"：CDK 超过有效期无法兑换
   提示 "背包空间不足"：请清理背包后重新兑换物品奖励
   五、管理员使用指南

4. 打开 CDK 管理界面
   游戏内输入命令：/cdkadmin
   需拥有管理员权限才能使用此命令

5. 创建 CDK
   选择奖励类型（物品 / 金钱 / 车辆）
   填写奖励内容：
   物品：填写物品名称（需与数据库中一致）
   金钱：填写金额数值
   车辆：填写车辆模型名称
   填写数量（物品和车辆为整数，金钱支持小数）
   点击 "创建 CDK" 按钮
   系统会生成唯一 CDK 码并显示创建成功提示

6. 管理 CDK 列表
   界面会显示所有 CDK 的状态（有效 / 已使用 / 已过期）
   可查看 CDK 对应的奖励内容和数量
   点击 CDK 项后的删除按钮可删除指定 CDK
   六、系统配置说明
   主要配置项位于server/main.lua的Config表中：
   配置项	说明	默认值
   DBTable	数据库表名	gege_cdk
   AllowedGroups	允许管理的用户组	{ ['superadmin'] = true, ['admin'] = true }
   CDKExpireHours	CDK 有效期（小时）	72
   CDKLength	CDK 码长度（不含分隔符）	16
   七、奖励类型说明
   物品奖励：
   需确保物品名称在 ESX 物品系统中存在
   会检查玩家背包空间是否充足
   金钱奖励：
   直接添加到玩家的现金账户
   支持小数金额（如 0.5 表示 50 cents）
   车辆奖励：
   会将车辆添加到玩家的车库
   自动生成格式为CDK-XXXX的车牌
   需确保车辆模型在游戏中存在
   八、常见问题排查
   无法创建 CDK：
   检查是否拥有管理员权限
   确认奖励内容填写正确
   兑换后未收到奖励：
   检查数据库中 CDK 状态是否已变为 "已使用"
   查看服务器控制台是否有相关错误信息
   确认奖励类型对应的系统功能正常
   界面无法打开：
   检查资源是否正确加载
   确认权限配置正确
   查看客户端控制台是否有错误提示
