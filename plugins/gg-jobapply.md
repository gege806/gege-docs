# gg_jobapply - 公职入职申请

玩家在招录点用瞄准交互打开入职表，支持入职、调转、内务投诉与内务公示。

## 需要什么

- ox_lib
- ox_target
- oxmysql
- qb-core / qbx_core / es_extended 任选其一
- 可选：lb-phone（自动识别联系电话）

## 安装

1. 把 `gg_jobapply` 放进 resources
2. `server.cfg` 写入：

```cfg
ensure ox_lib
ensure ox_target
ensure oxmysql
ensure lb-phone
ensure gg_jobapply
```

3. 重启服务器（表会自动创建 / 升级）

## 玩家怎么用

1. 走到招录点，瞄准前台
2. **填写入职申请**：选岗位 → 填表 → 呈报（电话可自动识别 LB 手机号）
3. **申请岗位调转**：在职公职可选目标岗位提交调转理由
4. **提交内务投诉**：阅读该局座右铭 / 内务职责 / 投诉流程后，按官方 IAB 格式填写（涉事人员姓名与警号/工号、投诉原因、证据、投诉人、证明人），勾选声明授权后提交并获取案件参考编号
5. **查看内务公示**：浏览已公开发布的内务通报
6. **我的记录**：查看入职 / 调转 / 投诉处理进度

内务窗口默认：LSPD、LSSD、BCSO、SAHP、EMS、市政厅。坐标可在配置中修改。

## 管理人员怎么用

1. 职级与职业权限达标后，选「审核入职 / 内务」或输入审核命令
2. 人事审核：入职、调转可批准 / 拒绝
3. 内务处理：立案调查、成立、不成立、结案，并可发布到公示栏
4. 可选命令查看公示栏

## 配置说明

- 招录地点：坐标、前台人员、地图标记、是否开放调转 / 投诉 / 公示
- `Config.IADepartments`：各局内务文案、人员称谓（警员 / 治安官 / 巡警 / 医护人员 / 公职人员）、声明与格式警告
- 入职表、调转表、内务投诉表字段可改（投诉表按称谓自动生成）
- 投诉类别可改
- 自动识别 LB 手机号开关
- 调转批准后是否自动改职业、是否保留原职级
- 人事审核权限、内务处理权限与最低职级
- 冷却时间、待审数量上限
