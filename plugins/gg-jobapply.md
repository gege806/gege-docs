# gg_jobapply - 公职入职申请

玩家在招录点用瞄准交互打开入职表，填写后提交，管理人员可在同地点或命令审核。

## 需要什么

- ox_lib
- ox_target
- oxmysql
- qb-core / qbx_core / es_extended 任选其一

## 安装

1. 把 `gg_jobapply` 放进 resources
2. `server.cfg` 写入：

```cfg
ensure ox_lib
ensure ox_target
ensure oxmysql
ensure gg_jobapply
```

3. 重启服务器（表会自动创建）

## 玩家怎么用

1. 走到招录点（警局前台、医院人事、警长署、市政厅等）
2. 对前台人员 / 区域用瞄准交互，选「填写入职申请」
3. 选择岗位，填写入职表后呈报
4. 在「我的申请」查看审核状态

## 管理人员怎么用

1. 职级达到配置要求，且职业在权限列表里
2. 在招录点选「审核入职申请」，或输入审核命令
3. 查看待审申请，批准或拒绝，可写审核意见
4. 申请人在线时会收到通知

可选：配置批准后自动入职。

## 配置说明

- 招录地点：坐标、朝向、是否生成前台人员、地图标记、公告文案
- 每个地点可挂多个岗位（岗位名、薪酬、编制、简介、任职要求）
- 入职表字段可增删改（姓名、年龄、电话、住址、经历、动机等）
- 申请冷却、最多待审数量
- 哪些职业能审哪些岗位、最低职级
- 审核命令名、是否批准后自动改职业

默认地点：洛圣都警局、皮尔博克斯医院、桑迪警长署、市政厅。按你服地图改坐标即可。
