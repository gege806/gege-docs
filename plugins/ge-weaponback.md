# ge_weaponback

根据快捷栏里的武器，在角色背部和腰部显示挂枪，可调位置，别人也能看到。

当前版本：**v1.3.3**

## 功能

- 支持 ESX / QB / QBOX，自动识别框架
- 四个挂点：背部左 / 背部右 / 腰部左 / 腰部右
- 读取快捷栏（默认 1–5）武器并显示
- 可视化编辑：拖位置、调旋转，保存到数据库
- 挂载预设：把当前方案存成预设，一键套用
- 预设可生成分享码，别人输入即可导入使用
- 服务器新增或替换的武器，背上尽量与手上外观一致
- 可显示瞄具、握把、消音等配件
- 手里拿着某把枪时，只隐藏这一把的背枪
- 上车、翻墙 / 攀爬时可隐藏
- 可同步给其他玩家看（双方都要有该武器资源）
- 关闭背枪手电，避免胸前发光
- 编辑器旋转可按 X / Y / Z 分别调整

## 依赖

- ox_lib
- ox_inventory
- oxmysql
- 框架三选一：es_extended / qb-core / qbx_core

## 安装

1. 把 `ge_weaponback` 放进 `resources`
2. 确认依赖已启动
3. `server.cfg` 示例：

```cfg
ensure oxmysql
ensure ox_lib
ensure es_extended
ensure ox_inventory
ensure ge_weaponback
```

（框架按实际改成 qb-core / qbx_core）

4. 数据库表启动时自动创建；也可手动执行插件内 SQL
5. 从旧版 qb-weaponback 升级时，启动会自动迁移旧挂载数据
6. 按需改配置后 `ensure ge_weaponback`

成功启动时控制台会打印框架名称。

## 使用

1. 武器放进快捷栏
2. 输入 `/weaponback` 打开设置
3. 给挂点选枪、调位置和旋转后点「保存配置」
4. 快捷栏还有这把枪时，对应位置会显示
5. 拿出某把枪：只藏这一把背枪，其它照常显示
6. 服务器新增武器：先拿在手里再收枪，背上更容易对上正确外观

### 挂载预设

1. 调好挂点后，勾选要保存的挂点（例如只勾「背部左」）
2. 填写名称，点「保存当前预设」
3. 列表里点「应用」：只更新该预设里的挂点，其它挂点不动
4. 点「分享」：得到分享码（面板里也会显示）
5. 别人打开面板，输入分享码点「导入分享码」：导入并应用对应挂点
6. 不需要的预设可点「删除」

## 命令

| 命令 | 说明 |
|---|---|
| /weaponback | 打开背枪设置 |
| /wbdebug | 调试开关 |
| /wbcomponents | 配件调试信息 |

仅管理员可保存时，需具备对应管理员权限（ACE / 框架管理员组）。

## 配置说明

| 项 | 说明 |
|----|------|
| 框架 | 默认自动识别，也可手动指定 |
| 快捷栏槽位 | 哪些格子会显示为背枪 |
| 手持隐藏 | 拿着某把枪时是否只藏对应背枪 |
| 载具内隐藏 | 上车是否藏全部背枪 |
| 攀爬隐藏 | 翻墙 / 攀爬是否隐藏 |
| 必须先保存位置 | 开着则未在编辑器保存过的挂点不显示 |
| 编辑命令 | 默认 weaponback |
| 仅管理员保存 | 开着则普通人不能保存挂点 / 预设 |
| 用武器实体显示 | 开着时新增 / 替换武器和配件更准（建议开着） |
| 显示配件 | 是否显示瞄具等配件 |
| 关闭背枪手电 | 避免胸前发光 |
| 同步其他玩家 | 关了别人看不到你的背枪，人多可关省性能 |
| 进服延迟 | 进服多久后开始挂背枪 |
| 最多预设数 | 每人最多保存多少个预设 |
| 分享码长度 | 预设分享码位数 |

位置、旋转步进和挂点默认偏移可在配置里改。

## 常见问题

**快捷栏有枪但不显示**

- 确认在快捷栏指定槽位内
- 用 `/weaponback` 选好挂点并保存
- 若开启「必须先保存位置」，未保存不会显示

**服务器新增武器背上不对**

- 保持「用武器实体显示」开启
- 先拿在手里再收枪
- 确认该武器资源已启动，自己和别人客户端都有

**别人看到的和自己不一样**

- 对方也要有同一武器资源
- 确认已开启同步其他玩家

**分享码无效**

- 确认码输入正确（不区分大小写）
- 对方必须先点「分享」生成过码
- 导入方预设数量未达上限

**人多卡顿**

- 关闭同步其他玩家
