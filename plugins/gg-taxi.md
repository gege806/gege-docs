## 🛠️ 安装步骤

### 1. 依赖项
确保以下资源已安装并运行：

```
oxmysql          (必须)
ox_lib           (推荐，可在 config.lua 中切换)
lb-phone         (可选，LB 手机 APP)
```

### 2. 导入数据库
将 `sql/gg_taxi.sql` 导入你的数据库：

```bash
mysql -u root -p 你的数据库名 < sql/gg_taxi.sql
```

或在 HeidiSQL / phpMyAdmin 中执行 SQL 文件。

### 3. 放置资源
将 `gg_taxi` 文件夹放入服务器的 `resources` 目录：

```
server/resources/[jobs]/gg_taxi/
```

### 4. 添加到 server.cfg
```
ensure gg_taxi
```

### 5. 配置 config.lua
```lua
-- 选择你的框架
Config.Framework = 'ESX'   -- 'ESX' 或 'QB'

-- 选择通知系统
Config.DispatchSystem = 'ox_lib'

-- 是否使用 LB 手机
Config.UseLBPhone = true

-- 职业名称（需与数据库一致）
Config.TaxiJob = 'taxi'
```

```lua

    enabled     = true,
```

## ❓ 常见问题

**Q: 支持哪些框架？**  
A: ESX、QB-Core、QBOX，在 `config.lua` 中设置 `Config.Framework = 'ESX'/'QB'/'QBOX'`。

**Q: 通知系统如何切换？**  
A: 修改 `Config.DispatchSystem`，支持 `ox_lib`、`pNotify`、`okokNotify`、`mythic`、`esx`。

**Q: LB Phone APP 如何激活？**  
A: 确保 `lb-phone` 运行，设置 `Config.UseLBPhone = true`，`Config.LBPhoneResource = 'lb-phone'`。

**Q: 如何关闭司机注册审批要求？**  
A: 设置 `Config.Registration.autoApprove = true` 即可自动审批，或设置 `Config.Registration.enabled = false` 关闭注册系统。

**Q: AI备用出租车如何配置？**  
A: `Config.NPCFallbackTaxi.enabled = true`，并调整 `checkInterval`（检测间隔）和 `spawnDelay`（生成延迟）。

**Q: 提现系统如何限额？**  
A: 修改 `Config.Withdraw.maxPerDay`（每日上限）和 `Config.Withdraw.minAmount`（最低金额）。

**Q: 如何调整评分封禁阈值？**  
A: 在 `Config.RatingSystem` 中设置 `warnThreshold`、`suspendThreshold`、`fireThreshold`。

**Q: F6 音乐播放器如何填入音乐？**  
A: 在 `Config.DriverConsole.music.playlist` 中填入 MP3 直链（支持网易云、QQ音乐外链），或在游戏内 F6 → 自定义链接 实时输入。

**Q: 如何设置上车点为完全随机？**  
A: 设置 `Config.RandomPickupLocation = true`，并调整 `Config.RandomPickupRadius` 半径范围。

**Q: 排行榜重置周期如何设置？**  
A: `Config.Leaderboard.resetPeriod` 可设置为 `'daily'`、`'weekly'`、`'monthly'`、`'never'`。
