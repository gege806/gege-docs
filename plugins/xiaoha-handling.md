# 🚗 小哈调车 - 车辆数据修改插件

## 📖 脚本介绍

小哈调车是一款功能强大的FiveM车辆操控数据编辑器，让您可以在游戏内实时调整车辆的各项性能参数，无需重启服务器即可生效。

## ✨ 主要功能

### 🎛️ 车辆操控编辑
- **高级编辑器** - 完整的handling参数调整，支持所有原生操控属性
- **简化编辑器** - 简单易用的滑块界面，快速调整加速、极速、刹车等常用参数
- **实时预览** - 调整参数后可立即预览效果，满意后再应用

### 💾 配置管理
- **保存配置** - 将调整好的参数保存为配置文件，方便日后使用
- **加载配置** - 一键加载已保存的配置，快速应用到当前车辆
- **导出功能** - 导出为 `handling.meta` XML 格式，可用于永久修改车辆数据

### 🔐 车辆驾驶权限管理
- **按玩家限制** - 指定只有特定玩家才能驾驶某辆车
- **按职业限制** - 设置只有特定职业（如警察、医生）才能驾驶
- **职业等级要求** - 可设置最低职业等级要求
- **权限管理页面** - 统一管理所有车辆的驾驶权限配置

### 🌍 多框架支持
- ✅ ESX
- ✅ QBCore  
- ✅ Qbox

### 🌐 多语言支持
- 🇨🇳 简体中文
- 🇺🇸 English

## 📋 依赖项
- oxmysql
- ox_lib

## 🛠️ 安装说明
1. 将资源放入 `resources` 文件夹
2. 在 `server.cfg` 中添加 `ensure xiaoha-handling`
3. 导入 `install/database.sql` 到数据库
4. 根据需要修改 `config/config.lua` 配置文件
