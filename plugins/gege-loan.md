gege-loan · FiveM 多功能贷款系统

一个面向 **ESX / QB / QBX** 框架、通过 **lb-phone** 手机使用的综合贷款插件。

## ✨ 功能

| 功能 | 说明 |
|------|------|
| ⚡ 小额贷款 | **自动审批，秒到账** |
| 💳 信用贷款 | 根据**信用分**自动调整利率与额度 |
| 🚗 车辆抵押贷款 | 抵押车辆放款，逾期违约**自动没收**抵押车辆 |
| 🏢 企业贷款 | 仅限老板申请，放款到**企业对公账户(society)** |
| 🔁 每日自动扣款 | 调度器按周期自动从银行扣款还款 |
| ⏰ 逾期罚息 | 逾期自动按日加收罚息 |
| 🤝 担保人系统 | 选择担保人、对方确认、逾期代偿、追偿、信用联动 |
| 📊 信用分 (0-100) | 影响利率、额度，过低禁止贷款 |
| 🏬 贷款公司 | **使用物品打开平板**，公司端**审批 / 放款**、查看进行中与逾期、放贷概览 |

### 信用等级

| 信用等级 | 分数 | 利率折扣 | 额度加成 |
|---------|------|---------|---------|
| 优秀 | 80-100 | 9折 | +50% |
| 良好 | 60-79 | 正常 | 正常 |
| 一般 | 40-59 | +20% | -30% |
| 较差 | 0-39 | 禁止贷款 | - |

### 担保要求

| 借款人信用 | 担保要求 |
|-----------|---------|
| 80分以上 | 无需担保 |
| 60-79分 | 大额贷款需担保 |
| 60分以下 | 所有贷款需担保 |

**担保人责任：**
- 借款人逾期 7 天 → 担保人**代偿**
- 代偿后系统自动生成对借款人的**追偿**债权
- 担保人信用分与被担保人还款情况**联动**

## 📦 安装

1. 确保已安装依赖：`oxmysql`、对应框架（`es_extended` / `qb-core` / `qbx_core`）、`lb-phone`（同时用于自营公司「车辆估值」时调用手机相机拍摄车辆照片）。
2. 将 `vx-loan` 文件夹放入 `resources`。
3. **数据库自动创建**：资源首次启动时会自动建表（`vx_loan_credit` / `vx_loan_loans` / `vx_loan_payments`），无需手动导入。若想手动导入也可执行 `sql/vx-loan.sql`。
4. 在 `server.cfg` 中添加（确保在框架与 lb-phone 之后）：

```cfg
ensure oxmysql
ensure lb-phone
ensure vx-loan
```

5. （可选）赋予管理员权限以使用 `/setcredit`：

```cfg
add_ace group.admin vxloan.admin allow
```

## ⚙️ 配置

所有参数集中在 `config.lua`：

- `Config.Framework`：`auto` 自动识别，或手动指定 `esx`/`qb`/`qbx`。
- `Config.Loans`：四类贷款产品的利率、额度、期数、是否需抵押/对公、是否需公司审批 `companyApproval`。
- `Config.Company`：贷款公司平板（打开物品、限制职业、是否消耗物品）。
- `Config.Credit`：信用分等级、奖惩规则。
- `Config.Guarantor`：担保门槛、代偿天数。
- `Config.Repay`：扣款检查间隔 `CheckIntervalMs`、“一天”时长 `DayLengthMs`、罚息 `PenaltyDailyRate`、违约上限 `MaxOverdueDays`。
- `Config.VehicleValues`：车辆估值表（抵押额度 = 估值 × LTV）。

> ⏱️ 还款节奏由真实时间驱动：默认每 5 分钟检查一次，`DayLengthMs` 决定“一期”代表多长真实时间（默认 1 小时）。可按服务器节奏调整。

## 🕹️ 使用

- 玩家打开 **lb-phone** → 找到「贷款」应用。
- **首页**：查看信用分、等级权益、担保规则、当前负债。
- **申请**：选择产品 → 输入金额（车辆抵押需坐进车内，需担保时选择在线玩家）。
- **我的**：查看贷款、还当期 / 提前结清、偿还追偿债务。
- **担保**：查看自己担保的贷款。

收到担保请求时：可在应用内弹窗点击同意/拒绝，或使用命令 `/loanyes`、`/loanno`。

## 🏬 贷款公司（平板 · 审批放款）

部分贷款（默认 **信用 / 车辆抵押 / 企业**）改为**提交贷款公司审批**：玩家在手机申请后状态为「待审批」，由公司职员使用物品打开平板进行审批放款。小额贷款仍**自动审批秒到账**。

**使用：**

1. 在你的物品系统中添加物品 `loan_terminal`（名称可在 `Config.Company.item` 修改）。
   - QB/QBX：在 `qb-core/shared/items.lua` 增加该物品条目（`useable = true`）。
   - ESX：在 `items` 表中插入该物品。
   - **ox_inventory**：在 `ox_inventory/data/items.lua` 增加条目，并通过 `server.export` 绑定本资源的使用回调：

```lua
['loan_terminal'] = {
    label = '贷款公司平板',
    weight = 1000,
    stack = false,
    close = true,
    description = '贷款公司专用平板，用于审批放款',
    client = {
        image = 'loan_terminal.png', 
    },
    server = {
        export = 'gege-loan.useLoanTerminal', 
    },
},
```

> - ox_inventory 不使用 `useable` 字段；改由 `server.export` 在玩家「使用」物品时回调本资源的 `useLoanTerminal`（已内置）打开平板。
> - 物品名需与 `Config.Company.item` 一致；若设了 `Config.Company.consumeItem = true`，使用后会通过 `ox_inventory:RemoveItem` 扣 1 个。
> - 用 QBX + ox_inventory 时务必用上面的 `server.export` 方式（QB 的 `useable` 在 ox 下不会触发）。

2. 持有物品的玩家**使用该物品**即可打开「贷款公司」平板。也可用**命令**打开。
3. 平板内：
   - **待审批**：选择申请查看申请人、信用分、利率、期数、担保人、抵押车辆、**实名照片**，一键 **通过并放款** 或 **拒绝**。
   - **进行中**：查看所有还款中 / 逾期贷款。
   - **没收车辆**：查看因逾期违约被没收的抵押车，可**归还**给原车主或**拍卖**折现入金库。
   - **车辆估值（自营专属）**：玩家申请车辆抵押贷款**前**，须先由公司在此为车辆录入估值；估值在 `Config.Company.valuationHours`（默认 24）小时内有效，过期需重新估值。估值时点「用手机拍摄车辆照片」会调起 **lb-phone 相机**拍照并上传，照片随估值保存（点击列表缩略图可放大查看）。`Config.Company.valuationPhoto = true` 时照片为必填。
   - **数据统计**：**公司金库余额**、未结清总额、待审批 / 进行中 / 逾期数量。
     - **取钱**：从公司金库提现到操作员**现金**。
     - **存钱**：从操作员**银行**存入公司金库。

**配置 `Config.Company`：**

- `enabled`：总开关。
- `item`：打开平板的物品名（默认 `loan_terminal`）。
- `consumeItem`：使用时是否消耗物品（默认否）。
- `job`：限制可审批职业（如 `'loancompany'` 或 `{ 'loancompany', 'banker' }`）；`nil` 表示持有物品即可。

> 多公司模式下，**审批权限由各公司自己的 `Config.Companies[id].job` 决定**：员工打开平板时按职业匹配所属公司，平板内的申请、客户、金库、没收车、产品档位等数据都**只显示自己公司的部分**，**不能查看/切换到别的公司**。
>
> `allowCompanySwitch`（默认 `false`）：是否允许管理员在平板顶部切换查看其它公司页面。默认关闭——平板只打开本人对应的公司页面；设为 `true` 时，无所属公司的管理员可切换查看/管理任意公司。

**哪些贷款需公司审批**：由放贷公司的运营模式决定——**系统托管（hosted）** 全部自动放款；**自营（self）** 全部需公司在平板审批，并从公司金库出款。

## 🏢 多家贷款公司（系统托管 / 自营）

支持配置多家放贷公司，玩家在手机申请时**先选公司、再选产品档位**。在 `config.lua` 配置：

```lua
Config.MaxInterestRate = 0.30    -- 单期最高利率上限（所有公司不得超过，防黑心贷款公司）
Config.DefaultCompany  = 'system'

Config.Companies = {
    ['system'] = { label = '系统信贷', mode = 'hosted', job = nil,      society = nil,   valuationRatio = 1.0, order = 1 },
    ['maze']   = { label = 'Maze 银行', mode = 'self',   job = 'banker', society = 'bank', valuationRatio = 0.9, order = 2 },
}
```

- `mode = 'hosted'`（系统托管）：放款由**系统出钱**、使用默认产品（`Config.Loans`），全部**自动审批秒到账**，无需有人管理。
- `mode = 'self'`（自营）：放款从**公司金库**扣钱（需先在平板注资），所有贷款都**需该公司审批**；公司可在平板**自定义档位**。车辆抵押**不使用系统车价**，须由公司在平板「车辆估值」页**先行估值**（限时有效、含车辆照片），玩家方可凭该估值申请抵押贷款。
- `job`：该公司员工职业（决定谁能在平板里管理这家公司）。
- `society`：自营公司用于金库注资 / 提现互转的对公账户（可选）。
- `valuationRatio`：自营公司对抵押车的估值系数（`1` = 与系统一致，`0.8` = 打八折）。

**产品档位（自营专属）**：在平板「产品档位」页基于四类基础产品（小额 / 信用 / 车辆抵押 / 企业）**新增 / 启停 / 删除**自定义档位，可设名称、单期利率、额度区间、周期。利率始终受 `Config.MaxInterestRate` 封顶。系统托管公司直接使用默认产品，不可自定义。

**打开平板：** 用命令或物品打开平板。默认命令 `/loanoffice`（可在配置里修改或关闭）。

> 个人贷款放款为**现金**，需借款人在线；企业贷款放款到**对公账户**，借款人可离线。

> 💰 **公司金库**：玩家的每一笔**还款**（含担保人**代偿**、被没收车**拍卖**）会自动进入**对应放贷公司**的金库（按公司分区的数据表 `vx_loan_funds`），可在平板「数据统计」页**取钱 / 存钱**。自营公司放款也从本公司金库扣除。

> 🚗 **被没收车辆处置**：车辆抵押贷款逾期满 `MaxOverdueDays` 违约后，抵押车会被没收并标记 `collateral_state = 'held'`。在平板「没收车辆」页：
> - **归还**：把车还给原车主，停入 `Config.JG.returnGarage`（状态置为 `storedState`）。
> - **拍卖**：按 `Config.Company.auctionRatio`（默认 0.6）折现进入金库，并删除该车数据。

## 🚗 JG Advanced Garages 接入

在 `config.lua` 的 `Config.JG` 中配置（默认已开启）：

- `selectFromGarage = true`：车辆抵押时**从玩家名下车辆中选择**（关闭则改为"坐进车内抵押"）。
- 逾期违约没收时：先删除已生成在外的车，再把车辆改判给扣押车主并停入扣押车库（按你的车库标识填写）。
- 申请抵押贷款时会校验车辆**确属本人**，估值按车牌查 `model` 后用 `Config.VehicleValues` 计算，额度受 `估值 × LtvRatio` 限制。

> 没收逻辑基于标准车辆表（QB/QBX 的名下车辆表、ESX 的已拥有车辆表）。若你的车库为自定义存储，请自行对接没收后的车辆处理。

## 📈 信用看玩家的车（车辆资产授信）

`Config.Credit.VehicleAsset` 让玩家名下车辆作为资产**提升可贷额度**：

- 额度加成 = 名下车辆总估值 × `limitBonusRatio`，封顶 `maxBonus`。
- 通过 `appliesTo` 控制对哪些贷款类型生效（默认信用/抵押/企业生效，小额不生效）。
- 手机首页「车辆资产」区展示名下车辆数与可抵押资产。

## 🧪 调试

- `config.lua` 设 `Config.Debug = true` 打印日志。
- 控制台执行 `vxloan_runcycle` 手动触发一次扣款周期。
- `setcredit [playerId] [score]` 设置玩家信用分。
- UI 可直接用浏览器打开 `ui/index.html` 预览（内置 Mock 数据）。

## 注意事项

- 抵押车辆没收会尽量更新框架自带的车辆表；如使用自定义车库系统，请自行对接没收后的车辆处理。
- 企业对公账户依赖 `esx_society`（ESX）或 `qb-banking`/`qb-management`（QB/QBX）。
