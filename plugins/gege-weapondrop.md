# gege_weapondrop

枪战中被对方用枪打死时，手上那把枪会掉在地上。掉落处有光标，靠近按 E 做捡枪动作后拿走。死之前把枪收起来则不会掉。

当前版本：**v1.0.7**

## 功能

- 双方持枪对打，被打死才掉手上的枪
- 收枪后再死，枪不会掉
- 地上只显示光标提示（不生成枪模型）
- 靠近按 E，立刻进背包并播放捡枪动作
- 摔死、车撞、近战打死不会掉枪

## 依赖

- ox_lib
- ox_inventory

## 安装

1. 把 `gege_weapondrop` 放进 `resources`
2. `server.cfg`：

```cfg
ensure ox_lib
ensure ox_inventory
ensure gege_weapondrop
```

3. 按需改 `config.lua`

## 配置说明

| 项 | 说明 |
|----|------|
| 捡枪按键 | 默认 E |
| 捡枪距离 | 靠近多远可以捡 |
| 捡枪动作时长 | 仅表现用，进包不等待 |
| 地上停留时间 | 多久后自动消失，0 为不消失（默认不消失） |
| 必须被玩家打死 | 开着则 NPC / 自杀不掉 |
| 对方必须用枪 | 开着则近战、车祸不掉 |
| 光标类型 / 颜色 / 大小 | 地上提示外观 |
| 不掉枪职业 | 警察等职业可单独关掉 |

## 使用

1. 拔枪对打
2. 对方把你打死（枪还拿在手上）→ 掉落处出现光标
3. 走到光标处按 E，枪立刻进背包
4. 被打中之前把枪收回去 → 死后枪还在自己身上，不会掉
